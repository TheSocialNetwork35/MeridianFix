The five common reliability fixes below are retained from the first fork release. Fork changes: 2026-09-25, generated by Codex.

- AtomicConfigFile and ModernFixEarlyConfig: write complete sibling temporary file,
  resolve existing symlinks, use Properties-compatible encoding, atomically replace
  only after successful write, and clean up failed temporary files.
- ZipPackIndex: validate central-directory bounds/structure and canonical entry paths;
  iterative freezing/enumeration; support scoped prefix indexes; preserve unsupported
  ZIP64 fallback. FilePackResources caches failures until close.
- SingleThreadedWorkerService: reject null/after-shutdown nested submissions while
  preserving valid reentrancy and this game version's executor/mailbox type.
- ChunkAccessMixin: keep cached structure-reference views live when initially empty;
  retain this game's actual field name.
- Loader-specific build and metadata: exact game version, independent artifact name,
  explicit unofficial branding, original licenses/notices, source JAR, pinned toolchain,
  twelve tests and audit entrypoints. Upstream publishing targets removed; build-only CI.
- Original source credits, history, LICENSE and README/CONTRIBUTING are preserved.
  No AI logo, icon or gallery image is generated. Internal modernfix ID is retained.

Additional loader adaptation and exclusions, if any, are described in doc/FORGE_26_PORT.md.
