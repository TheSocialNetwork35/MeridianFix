# ModernFix Reforged

**Unofficial fork of [ModernFix](https://github.com/embeddedt/ModernFix) by embeddedt
and contributors, maintained by [TheSocialNetwork35](https://github.com/TheSocialNetwork35).**
Not endorsed by upstream, Mojang or Microsoft. Licensed LGPL-3.0-or-later;
original copyrights and component notices are preserved.

Independent changes address failure-safe configuration replacement, ZIP indexing and
fallback, executor shutdown correctness and live structure-reference views. No measured
FPS, memory or loading-time improvement is claimed.

The original 26.3 NeoForge alpha was named MeridianFix. That historical artifact and
its source retain that name; the current project name is ModernFix Reforged. Do not
install multiple variants or original ModernFix together: they share mod ID `modernfix`.

## This branch: Forge 26.3

Main targets Minecraft 26.3, Forge 66.0.3, Java 25, ForgeGradle 7.0.29 and Gradle 9.7.1.
Build: `./gradlew --no-daemon build`.
Mixin audits: `./gradlew runServer runClient -PreforgedAudit=true`; add
`-PreforgedFeatureLevel=BETA` to check beta-tier transformations.

See [validation](release/TEST_REPORT.md) and [Forge exclusions](doc/FORGE_26_PORT.md).
Development startup audits and component tests do not establish full gameplay,
world persistence, modpack or operating-system compatibility. Client and server
installation are optional. This alpha excludes documented NeoForge-only features.
