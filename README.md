# ModernFix Reforged — Minecraft 26.3 / Forge

Unofficial ModernFix fork, maintained by TheSocialNetwork35. Not endorsed by
embeddedt, ModernFix contributors, Mojang or Microsoft. This branch targets
**Forge 66.0.3 and Java 25** with ForgeGradle 7.0.29 / Gradle 9.7.1.
It is a separate port from the NeoForge artifact.

Independent fixes address configuration replacement, ZIP indexing, executor shutdown
and live structure-reference views. See release/TEST_REPORT.md for actual validation
and doc/FORGE_26_PORT.md for loader-specific exclusions. No broad gameplay/modpack or
performance guarantee. Original LGPL-3.0-or-later terms and credits remain in force.

Build with Java 25: `./gradlew --no-daemon build`.
Startup Mixin audits: `./gradlew runServer runClient -PreforgedAudit=true`;
add `-PreforgedFeatureLevel=BETA` for the beta tier. These commands exit during setup.
New fork code and publishing text were generated by Codex; public Modrinth eligibility
is not cleared. Original notices and source history are retained.
